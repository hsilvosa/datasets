# GDELT 1.0 Events

This dataset contains a fixed historical snapshot of events extracted by the GDELT Project from worldwide news reporting. Events are represented using the CAMEO taxonomy and include coded actors, event type, location, source counts, tone, and source URL when supplied by GDELT.

The snapshot covers source archives from 1979 through 14 August 2026. It contains the complete GDELT 1.0 event files rather than the reduced country-level aggregation. GKG, Mentions, and GDELT 2.0 are not included.

The source records are algorithmically extracted from news. They describe media reporting and should not be treated as independently verified facts or as a complete measure of real-world activity. Coverage changes substantially across time, countries, languages, and publishers.

Raw GDELT ZIP archives are retained locally for reproducibility but are not part of the prepared release. Machine-readable provenance records the fixed cutoff, source filenames, sizes, published MD5 values, and locally calculated SHA-256 checksums.
